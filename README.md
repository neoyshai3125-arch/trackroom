# TRACKROOM v6.2 — 전체 화면 음악 공간 + 왼쪽 메뉴 + 음악 추가 버튼

이 패치는 v6.1.1의 아티스트 검색 결과 압축 CSS 수정도 포함합니다. **서버, 데이터베이스 및 사용자·방·추천곡 스키마를 수정하지 않습니다.**

## 바뀐 화면

- 방에 들어가면 상단 사이트 헤더나 기존 큰 방 제목 영역 없이 **무한 버블 캔버스가 브라우저 화면을 가득 채웁니다.**
- **왼쪽 위 ≡ 메뉴:** 초대 링크 복사(기존 복사 동작), 프로필 설정(기존 닉네임/음원 플랫폼 편집창), 메인 화면으로 돌아가기. 바깥 누르기·닫기·Esc로 닫을 수 있습니다.
- **오른쪽 아래 + 음악 추가:** 기존 Apple/iTunes·Last.fm 곡/아티스트/앨범 검색 패널을 그대로 엽니다.
- 드래그/핀치/줌/커버 재검색 등 기존 버블 탐색 기능을 유지하며 확대/축소 도구는 화면 왼쪽 아래로 이동합니다.
- 데스크톱·모바일 화면을 모두 고려했습니다.

## 업데이트 방법

업데이트 ZIP의 **세 파일만** GitHub에서 같은 경로에 교체하세요.

```text
public/index.html
public/app.js
public/style.css
```

`server.py`, `requirements.txt`, `DATABASE_URL`, `LASTFM_API_KEY`는 **변경하지 마세요**. Render에서 배포가 끝나면 Ctrl+Shift+R로 캐시를 새로 고치세요.

회원·방 데이터 보존 조건: PostgreSQL을 이미 연결했다면 연결 주소를 바꾸지 않고 유지하세요. Render 임시 SQLite를 쓰고 있다면 재배포 시 데이터 손실 가능성이 여전히 있습니다.

이 프로젝트는 기존 코드로부터 만든 UI 패치입니다. 실제 웹 서비스 API 및 호스팅은 배포 후 사용자가 확인해야 합니다.
