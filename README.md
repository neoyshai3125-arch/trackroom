# TRACKROOM v6.3 — 모바일 빠른 조작 버튼

기준: TRACKROOM v6.2 전체화면 버전(아티스트 카드 수정 포함).

- 모바일(화면 너비 720px 이하): `DRAG TO EXPLORE / PINCH TO ZOOM` 안내 문구와 기존 확대·축소·초점·셔플·커버 복구 막대를 숨김. 손가락 드래그/핀치 확대 동작은 유지.
- 모바일 오른쪽 하단: 셔플, 음악 추가, 초점 설정의 48px 터치 버튼 3개.
- 초점 설정: 카메라 위치와 배율을 초기화(중앙, 100%). 셔플: 추천곡 중 다른 곡으로 이동.
- 기존 앨범 커버 복구 기능은 삼선 메뉴 → 앨범 커버 다시 찾기에서 접근.
- PC: 기존 화면과 조작 버튼 유지.
- 데이터베이스 및 서버 코드는 건드리지 않음. 기존 회원, 방, 곡 및 Neon DB는 유지됨(이미 DB에 저장된 경우).

## 적용
`public/index.html`, `public/app.js`, `public/style.css` 세 파일을 GitHub 저장소의 같은 경로에 교체해. ZIP을 GitHub에 통째로 업로드하지 않고 압축을 풀어 파일 단위로 교체해야 함. Commit 후 Render 자동 배포, 휴대폰 브라우저 새로고침.
