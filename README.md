# TRACKROOM v5.3 — 앨범 커버 검색 보완

이 버전은 v5.2의 **앨범 커버 매칭이 지나치게 엄격해서 대부분의 Last.fm 곡이 커버 없이 나오는 문제**를 개선합니다.

## 변경된 내용

- Last.fm에 표시되는 제목 외에 **Last.fm 공식 곡 링크의 실제 제목·아티스트 표기**도 비교합니다. (예: 한국어 제목과 영문 제목이 다른 경우)
- 아티스트만 검색했을 때 Apple/iTunes의 처음 150곡에 없는 곡이라면, 검색 결과 상위 4곡까지 제목+아티스트로 추가 조회합니다.
- Apple/iTunes 요청에 실패하면 Render 로그에 메시지를 남깁니다. Last.fm 검색 자체는 계속 작동합니다.
- 기존 음악 등록·로그인·버블 탐색·커버 복원 기능을 유지합니다.

## 적용 방법

업데이트용 ZIP의 `server.py`를 GitHub `trackroom` 저장소 **최상위의 `server.py`**와 교체하세요. `public` 파일은 변경하지 않습니다. Commit 후 Render 자동 재배포를 확인하세요.

## 검증 및 한계

서버 단위 테스트는 외부 API의 **모의 응답**으로 통과했습니다. 실제 iTunes API 연결 및 사용자의 라이브 Render 사이트는 여기에서 직접 검사할 수 없으므로, 실서비스 결과는 배포 후 확인이 필요합니다. Apple/iTunes 카탈로그에 없는 곡, 표기가 다른 일부 곡은 여전히 커버가 없을 수 있습니다. 한국 Apple Music과 미국·일본 iTunes Store는 서로 다른 카탈로그입니다.

참고: iTunes Search API에서 받은 커버는 Apple이 명시한 콘텐츠 홍보 및 스토어 연결 등의 약관을 따라야 합니다. 별도 캡처/재저장을 하지 않습니다.
