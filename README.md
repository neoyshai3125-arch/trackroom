# TRACKROOM — 음악 추천방 MVP

음원 파일을 업로드하거나 재생하지 않고, **친구들과 음악 정보를 공유하는 웹사이트**입니다.

## 바로 실행하기

1. Python 3.9 이상 설치
2. 이 폴더에서 터미널 실행
3. 명령 입력:

   ```bash
   python server.py
   ```

4. 브라우저에서 `http://localhost:8000` 접속

라이브러리 설치는 필요하지 않습니다. 기본 포트는 8000입니다.

## 기능

- 8자리 랜덤 코드로 방 만들기 / 참가
- 초대 링크 공유 (`/?room=...`)
- 노래 제목, 아티스트, 추천 이유, 원본 음악 링크 등록
- 좋아하는 구간 시작/끝을 `m:ss`로 저장 (재생은 하지 않음)
- 최신순/인기순, 좋아요, 내 추천곡 삭제
- 8초 간격으로 새 추천곡 자동 확인
- SQLite 데이터 저장 (`trackroom.sqlite3` 자동 생성)
- 회원가입 없는 시범 운영: 브라우저별 고유 ID를 로컬에 보관

## 친구와 실제로 공유하려면

`localhost`는 **내 컴퓨터에서만** 열립니다. 친구들이 각자 접속할 수 있게 하려면 이 서버를 인터넷에 배포하거나 같은 와이파이의 컴퓨터 IP와 포트를 열어야 합니다.

- 호스팅 시 `PORT` 환경변수에 서비스가 지정한 포트를 설정하세요. 기본적으로 `0.0.0.0`에 바인딩합니다.
- 서비스가 재시작되어도 데이터를 유지하려면 **영구 스토리지**가 필요합니다. 임시 파일시스템에 배포하면 SQLite 데이터가 사라질 수 있습니다.
- 개인 데이터 없이 시연하기 위한 MVP입니다. 공개 운영 전에는 회원 인증, 관리자 신고/차단, 스팸 방지/접근 제한, 개인정보 처리 및 백업을 추가하세요.
- 브라우저에 저장된 ID는 **보안 인증 수단이 아닙니다**. 따라서 이 버전은 친한 친구 간 테스트용입니다.
- HTTP 대신 HTTPS를 사용하는 호스팅을 권장합니다.

## 향후 Spotify·Apple Music·멜론 연동

현재 `songs` 테이블의 `music_url`, `start_seconds`, `end_seconds`가 추후 연결을 위한 기본 데이터입니다.
공통 음원 매칭을 위해 향후 `isrc`, `spotify_track_id`, `apple_music_id` 등을 추가할 수 있습니다. 플랫폼별 자동 재생에는 각각의 API 이용 조건, 이용자 구독 상태, 음악 이용 허락 검토가 필요합니다.

## 구조

```

├── public/
│   ├── index.html     # 페이지
│   ├── style.css      # 디자인
│   ├── app.js         # 사용자 인터랙션
│   └── favicon.svg

```

## 데이터

`trackroom.sqlite3` 파일만 백업하면 테스트 데이터가 유지됩니다. 파일은 첫 실행 때 자동 생성됩니다.
