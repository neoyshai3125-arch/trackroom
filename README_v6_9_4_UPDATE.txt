TRACKROOM v6.9.4 — 앨범 원 전체로 DJ 스크래치 조작

대상: 기존 TRACKROOM v6.9.3 설치 후 적용.

- 원형 재생 화면에서 진행 링뿐 아니라 앨범 커버의 원 안쪽 아무 곳을 잡고 원을 돌리듯 움직이면 이동한 각도에 맞춰 재생 위치 조절.
- 처음 누를 때는 시간 위치가 갑자기 뛰지 않음: 현재 위치에서 손가락 회전량만큼 가감.
- 손가락을 돌릴 때 앨범 이미지도 실제로 회전하고, 손을 떼면 미리듣기 재생 위치 확정.
- 중앙 재생/일시정지 버튼, 원 바깥 이전/다음 버튼, 하단 재생바와 배경 탭 닫기 동작은 그대로.
- 터치와 마우스 포인터, 키보드 화살표/Home/End 지원.
- 30초 Apple 미리듣기가 제공되는 곡에서 조작 가능. 음원 미리듣기가 없거나 길이를 아직 받지 못한 경우 조작 비활성.

적용: ZIP을 풀고 public, frontend, tests 폴더를 GitHub 저장소 루트에 같은 경로로 업로드/덮어쓰기. Render의 최신 커밋이 Live인지 확인. PWA 앱 종료 후 재실행. v6.9.4 표시 확인.

회원정보/방/음악 DB와 Render 환경변수는 변경하지 않음. 기존 server.py는 변경하지 않음.
