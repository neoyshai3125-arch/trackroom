TRACKROOM v6.9.3 — 겹침 방지 및 원형 DJ 스크래치

대상: TRACKROOM v6.9.2가 이미 적용된 GitHub 저장소 (더 이전이라면 6.9.2부터 적용)
서버, DATABASE_URL, 회원, 방, 노래 데이터는 변경되지 않습니다.

변경:
1. 방 버블 탐색: 기존에는 선택한 중앙 원을 1.5배 키워 주변 원들과 겹침. 재생 중 주변 원 0.76x, 선택 원 1.14x로 조절해 상대 크기는 정확히 1.5배(1.14/0.76)가 되면서 겹침을 줄임. 미리듣기 종료 시 원래 크기로 복귀.
2. 확대 재생 화면: 앨범 커버 바깥쪽 진행 링을 한 손가락으로 시계/반시계 방향으로 돌려 미리듣기 재생 위치 이동. 손을 뗄 때 seek 확정; 중앙 재생/일시정지 버튼 및 원 바깥 이전/다음 버튼은 유지. 키보드 화살표, Home, End 지원.
3. 하단 재생바는 확대 화면에서도 유지, 배경 터치 시 기존 버블 탐색으로 돌아감.
4. 서비스 워커 캐시 버전 갱신.

설치:
- ZIP을 압축 해제하고 public, frontend, tests 폴더를 GitHub 저장소 루트에 같은 경로로 업로드(덮어쓰기).
- README_v6_9_3_UPDATE.txt는 참고용.
- GitHub Commit changes 후 Render 최신 커밋 Live 확인. 설치된 앱 완전 종료 후 재실행.
- 방 메뉴에 v6.9.3 표시 여부 확인.
- 원형 조절은 Apple 미리듣기 오디오가 준비된 동안에만 동작(제공하지 않는 곡에서는 비활성).

주의: '1.5배'는 기존 화면에서 이미 큰 중앙 원에 또 1.5배를 곱하는 것이 아니라, 재생 중 주변 원과의 상대 크기입니다.
