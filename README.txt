TRACKROOM v6.1.1 — 아티스트 검색 결과 카드 표시 오류 수정 (재제작)

문제: 아티스트 50개가 검색되어도 결과 카드가 가로줄처럼 납작하게 표시됨.
수정: 스크롤 목록 내부 아티스트 카드의 flex 축소를 금지하고 최소 높이를 지정함.

설치 방법
1. 이 ZIP을 압축 해제합니다.
2. GitHub 저장소의 public/style.css 파일을 ZIP의 public/style.css로 교체합니다.
3. Commit changes 후 Render 배포가 완료되면 Ctrl+Shift+R로 새로고침합니다.

이 파일은 오직 CSS만 변경하며 회원정보, 방, 데이터베이스에는 영향을 주지 않습니다.
기존 v6.1.1과 동일한 기능 수정이며 v6.2 적용 시에는 필요 없습니다.
